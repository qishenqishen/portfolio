# Mealog Interactive Demo

Mealog is a slow social product concept that turns meals into quiet memory records.

## What This Demo Shows

- Add a meal memory with title, place, people, mood, photo, and note.
- Switch the phone preview between Today, Month, and People views.
- Watch monthly stats, relationship signals, and AI-assisted recap text update instantly.
- Keep demo data locally in the browser with `localStorage`.

## How To Run

Open `index.html` directly in a browser, or serve this folder with any static file server.

No install step or backend is required.
